# ui-contract skill

[ui-contract](https://github.com/xjcloudy/ui-contract) 的 Agent 使用技能（SKILL.md 格式）。

覆盖：接入自己的项目、日常校验命令、measure 前置条件、结果处置与基线棘轮、写自己的规则包、overrides 覆盖、常见坑与排障顺序。

## 安装

复制到 skill 根目录即可（DSH 扫描 `~/.dsh/skills`、项目 `.agents/skills` / `.dsh/skills`）：

```sh
git clone https://github.com/xjcloudy/ui-contract-skill ~/.dsh/skills/ui-contract
```
